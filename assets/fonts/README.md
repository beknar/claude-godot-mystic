# Fonts

Pixel fonts for the game's UI (`scripts/pixel_fonts.gd` loads them with
antialiasing, hinting, and subpixel positioning off, at whole multiples of
each font's pixel grid). These are free fonts, so unlike the purchased packs
in `assets/pack/` they are kept in git, each with its licence.

| File | Font | Use | Pixel grid (font size for 1 px) | Source | Licence |
|---|---|---|---|---|---|
| `PixelifySans.ttf` | Pixelify Sans (variable, default weight 400) | body text, HUD, messages, menus (Painted Lands) | 11 | [Google Fonts](https://fonts.google.com/specimen/Pixelify+Sans) | SIL OFL 1.1 (`OFL-pixelifysans.txt`) |
| `JacquardaBastarda9.ttf` | Jacquarda Bastarda 9 | titles and map-type names (words only: its digits are old-style) | 13 | [Google Fonts](https://fonts.google.com/specimen/Jacquarda+Bastarda+9) | SIL OFL 1.1 (`OFL-jacquardabastarda9.txt`) |
| `Jacquard12.ttf` | Jacquard 12 | big titles | 21 | [Google Fonts](https://fonts.google.com/specimen/Jacquard+12) | SIL OFL 1.1 (`OFL-jacquard12.txt`) |
| `Jersey10.ttf` | Jersey 10 | node names on the strategic map, coins and other numbers; Pixel Crawler headings | 18.67 | [Google Fonts](https://fonts.google.com/specimen/Jersey+10) | SIL OFL 1.1 (`OFL-jersey10.txt`) |
| `Silkscreen.ttf` | Silkscreen (capitals) | tiny labels: hints, legends | 8 | [Google Fonts](https://fonts.google.com/specimen/Silkscreen) | SIL OFL 1.1 (`OFL-silkscreen.txt`) |
| `Micro5.ttf` | Micro 5 | tiny labels (alternative to Silkscreen) | 11 | [Google Fonts](https://fonts.google.com/specimen/Micro+5) | SIL OFL 1.1 (`OFL-micro5.txt`) |
